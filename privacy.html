privacy policy

// data collection

Our authentication infrastructure limits profile collection strictly to assets mandatory for software license validation and client synchronization. We securely capture Hardware IDs (HWIDs) for device verification locks, alongside cryptographic session tokens generated during application launch parameters. To format custom user dashboards, basic discord profiles (User ID, username, and avatar URLs) are referenced dynamically.

// discord bot tracking

Our community helper bot functions solely on an interactive, on-demand transaction model. The bot framework does not monitor, cache, or harvest channel message contents, streaming presence layers, or off-platform user operations. Text interactions are parsed in real-time exclusively to address direct developer API executions or validation command sequences.

// automatic deletion logs

To sustain complete data minimisation protocols, our backend MySQL databases apply automated retention loops. Upon the full expiration of an active software license string, matching system records and user profile data configurations are systematically cleared from our servers.

// user control & erasure rights

Clients retain absolute governance over their tracked information profiles. Active users can demand immediate manual eradication of telemetry records, historical transaction charts, or license bindings at any interval prior to standard automated purge routines by opening an active management ticket inside our community infrastructure.
